## Experience mapped here

Private-sale and used-car listing work: honest listing copy, photo shot lists, enquiry routing, and a simple listing page so a buyer can see condition, price, and next step without hunting. No dealer CRM claims. No personal seller names.

## What Jade actually does in this vertical

- **Listing copy:** year / make / model placeholders, mileage, condition notes, must-know caveats in plain UK English.
- **Photo / ops:** exterior, interior, odometer, tyres, title paperwork shot list; publish order for Marketplace / Craigslist-style posts.
- **Docs:** buyer enquiry checklist, document packet list (title, service records placeholders), definition of done before going live.
- **Presentations:** short status one-pager when a co-seller or family stakeholder needs alignment.
- **Web mockup:** accessible single-vehicle listing sketch (`web/index.html`) with primary enquiry call to action (CTA).
- **Full-stack software engineering (FS SWE):** only if scoped (form → email / sheet); this folder is mostly marketing + ops + HTML.
