# Ops notes · Private Car Sale

## How Jade runs this lane

1. **Facts first:** year, make, model, trim, mileage, colour, title status, known issues ... write only what is confirmed.
2. **Photo set:** daylight exterior (four corners), interior, dash/odometer, tyres, under-bonnet if safe, any damage honestly framed.
3. **Listing copy:** one honest headline, specs block, condition paragraph, how to enquire (no pressure language).
4. **Channels:** Marketplace / local classifieds / simple HTML listing page ... same facts everywhere.
5. **Close-out:** when sold or withdrawn, take listings down the same day; archive docs privately (not in git).

## Experience used

Private-sale listing ops: marketing copy, photo discipline, enquiry triage, document packet readiness. Jade🪴 delivery here is clarity and handoff, not dealership polish.
