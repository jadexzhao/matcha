# Handoff checklist · Private Car Sale

## Before publish

- [ ] Year / make / model / mileage match the vehicle (no placeholders left live)
- [ ] Photo set covers exterior, interior, odometer, known wear
- [ ] Price and location strings are intentional (or clearly "enquire")
- [ ] Title / service-record packet listed privately for in-person review
- [ ] Enquiry CTA works on mobile
- [ ] Heading order logical (one h1 on the listing page)
- [ ] Colour contrast readable; link text describes destination

## After publish

- [ ] Same facts on every channel (no drift between Marketplace and the HTML page)
- [ ] Seller knows how to edit price and mark as sold
- [ ] When sold or withdrawn: listings removed; open questions closed in `ops-notes.md`
