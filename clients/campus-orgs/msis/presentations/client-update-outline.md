# Client update outline · MSIS

1. **Where we are** ... one sentence in plain English (no jargon pile-up).
2. **What shipped** ... mockup / docs / marketing / code slice.
3. **What we need from you** ... data samples, access, stakeholder sign-off.
4. **Next two weeks** ... concrete, dated if known.
5. **Risks** ... only real ones (missing schema owner, missing access).
