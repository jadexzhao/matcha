# Client update outline · Undergraduate Research Experience

1. **Where we are** ... one sentence, no jargon.
2. **What shipped** ... mockup / docs / marketing / code.
3. **What we need from you** ... copy sign-off, brand files, hours, booking link.
4. **Next two weeks** ... concrete, dated if known.
5. **Risks** ... only real ones (missing copy, missing access).
